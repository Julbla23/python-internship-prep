🔵 LISTY (list):

Lista:

przechowuje wiele elementów
jest mutowalna (można zmieniać)
ma indeksy od 0
Tworzenie listy
tasks = ["gym", "study", "shopping"]
Indeksy
print(tasks[0])  # gym
print(tasks[1])  # study
Dodawanie elementu
tasks.append("python")

Wynik:

["gym", "study", "shopping", "python"]
Usuwanie
tasks.remove("gym")

lub:

tasks.pop()
Sprawdzanie długości
len(tasks)
Sprawdzenie czy istnieje
if "study" in tasks:
    print("Exists")
Iteracja po liście
for task in tasks:
    print(task)

🔵 SŁOWNIKI (dict)

Słownik:

przechowuje dane w formie:
klucz: wartość
bardzo ważny w backendzie i API
Tworzenie słownika
task = {
    "id": 1,
    "title": "Learn Python",
    "done": False
}
Pobieranie wartości
print(task["title"])
Dodawanie nowego pola
task["priority"] = "high"
Zmiana wartości
task["done"] = True
Usuwanie
del task["priority"]
Iteracja po słowniku
Po kluczach
for key in task:
    print(key)
Po wartościach
for value in task.values():
    print(value)
Po kluczu i wartości
for key, value in task.items():
    print(key, value)

for

range()
for i in range(5):
    print(i)

Wynik:

0
1

enumerate()

Przydatne do numerowania.

tasks = ["gym", "study"]

for index, task in enumerate(tasks):
    print(index, task)
while

Działa dopóki warunek jest True.

Przykład
count = 0

while count < 5:
    print(count)
    count += 1

    return result

b = 3

result = 6

return 6
🔥 return vs print

To JEDNA z najważniejszych rzeczy w Pythonie.

🔴 print()

Tylko pokazuje coś na ekranie.

def add(a, b):
    print(a + b)
Wynik
add(2, 3)

pokazuje:

5

ALE...

Problem
result = add(2, 3)

result będzie:

None
🔵 Dlaczego?

Bo funkcja NIC nie zwróciła.

Pokazała wynik, ale go nie oddała.

✅ return
def add(a, b):
    return a + b
Teraz:
result = add(2, 3)

result będzie:

5

    for user in users:
        if user["username"] == username:
            return user

    return "User not found"
